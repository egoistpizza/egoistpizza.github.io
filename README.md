# Portfolio Website

![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg) ![Status: Active](https://img.shields.io/badge/Status-Active-success.svg)

Personal portfolio website built with the Catppuccin theme (Mocha). Designed for a modern, minimalist, and developer-centric look. Supports multi-language switching (TR/EN/DE).

## 🛠 Tech Stack
* **Core:** HTML5, CSS3, JavaScript (Vanilla)
* **Theme:** [Catppuccin Mocha](https://github.com/catppuccin/catppuccin)
* **Icons:** Font Awesome
